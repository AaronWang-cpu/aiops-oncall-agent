# 收敛工作区并重做诊断页

## Why

工作区同时提供与告警处理无关的对话入口和文档管理入口，演示与维护面积被无关能力摊薄；而真正与告警处理有关的核心能力反而没有暴露完全：诊断后端已经返回持久化的证据记录、查询账本与预算用量，前端却只能展示模型话术、工具名与证据 ID，运维人员看不到工具真实返回的日志正文、指标序列与变更明细。

## What Changes

- 删除前端对话与知识库模块（视图、组件、store、客户端及其测试），默认路由、通配路由与登录后落地页改为智能诊断工作区，侧栏只保留智能诊断与 MCP 连接。
- 重排诊断工作区：顶部命令带、左侧来源列（告警、历史、案例）、中间过程列（任务卡、实时时间线、执行链、报告）、右侧检查器列（结论与假设、现场证据、调查账本三个视图）。
- 新增现场证据视图与证据抽屉：按 kind 分组展示持久化证据，打开任一条可看到指标点、日志记录与变更记录，并明确说明被截断的范围。
- 新增调查账本视图：展示轮次/工具调用/内部往返用量与阶段截止时间，以及每次查询的问题、工具、状态、失败原因与参数。
- 执行链与假设依据中的证据引用可直接打开证据抽屉。
- 任务卡进度改为只使用后端阶段进度，移除前端估算值。

## Capabilities

- `aiops-diagnosis-ui`（修改布局类需求，新增证据与账本需求）
- `vue-app-shell`（修改路由需求，移除会话侧栏需求）
- `chinese-ai-workspace-experience`（修改工作区场景描述）
- `chat-experience`（移除）
- `knowledge-base-ui`（移除）

## Impact

- 仅影响 `apps/frontend`：后端 API、共享契约、数据库结构与迁移均不变。
- 对话与知识库的 HTTP 能力保留，仍可由其他客户端使用；本次只移除前端入口与展示。
- 既有历史诊断（含旧引擎产生的证据形状）继续可读，证据摘要为 JSON 字符串时以可读标签代替原文。

## Out of Scope

- 不新增或修改任何后端端点、合同字段与持久化结构。
- 不删除后端对话、知识库、RAG 相关代码与测试。
